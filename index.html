Engenharia Reversa & Inovação

O Dilema do Bluetooth no PC & A Ponte GhostPad

Jogar com controle sem fio no computador geralmente exige dongles proprietários, cabos incômodos ou adaptadores Bluetooth USB com alta perda de pacotes e desemparelhamentos frequentes.

Os Obstáculos Tradicionais

  • × Placas-mãe desktop sem módulo Bluetooth integrado.
  • × Dongles USB baratos que sofrem interferência de 2.4GHz e derrubam a conexão.
  • × Controles DualShock 4 e genéricos não reconhecidos nativamente por jogos que só aceitam XInput.
  • × Falta de cabo USB longo para jogar confortavelmente no sofá ou cama.

A Solução Elegante GhostPad

  • ✓ O smartphone possui antenas Bluetooth e Wi-Fi de alta potência com excelente estabilidade.
  • ✓ Nenhum aplicativo precisa ser baixado na Play Store ou App Store: funciona direto no navegador.
  • ✓ Driver de kernel ViGEm emula um Xbox 360 genuíno: suporte nativo a 100% dos jogos da Steam.
  • ✓ Transmissão ultra-rápida via WebSocket seguro local (latência média inferior a 3ms).

Pareamento Bluetooth HID Nativo

O controle (DualShock 4, DualSense, Xbox, 8BitDo ou genérico) conecta-se diretamente ao smartphone via Bluetooth HID padrão. Nenhum driver especial é necessário no celular, pois o kernel do Android/iOS gerencia a pilha Bluetooth e expõe o periférico como Standard Gamepad.

navigator.getGamepads() // Gamepad API

Engenharia de Software

Pilha Tecnológica & Arquitetura de Baixo Nível

Cada componente do GhostPad foi escolhido para minimizar o overhead de sistema e garantir resposta instantânea em jogos competitivos.

Driver ViGEmBus

O Virtual Gamepad Emulation Bus opera no anel 0 (Ring-0 Kernel Mode) do Windows. Ele injeta comandos diretamente no barramento USB do sistema operacional, tornando o GhostPad invisível para anticheats como Vanguard ou Easy Anti-Cheat.

XUSB.SYS vgamepad Ring-0 Kernel

Python Asyncio & aiohttp

O servidor de ponte opera com loops de eventos não-bloqueantes. Conexões de clientes e transferências de pacotes não concorrem com a renderização da interface e alcançam milhares de frames por segundo com consumo residual de CPU (< 0.5%).

Event Loop Threading Event WebSocket WSS

Criptografia Dinâmica x509

Geração pontual de pares de chaves RSA 2048-bit e certificados x509 com extensão SubjectAlternativeName embutindo o endereço IPv4 local (ex: 192.168.1.x). Garante conformidade com as políticas rígidas de HTTPS dos navegadores modernos.

cryptography RSA 2048 TLS 1.3

Interface Futurista Flet

Construído sobre o motor Flutter adaptado para Python, o GhostPad oferece aceleração gráfica por hardware com paleta grafite / obsidian, cantos hiperbólicos suaves, micro-animações responsivas e painel de controle intuitivo.

Flet Desktop Hardware Skia Dark Graphite

Pareamento Instantâneo QR Code

A biblioteca segno compila matrizes QR bidimensionais puras em tempo de execução contendo a URL exata com o IP detectado na interface de rede privada. Basta apontar a câmera do celular para conectar sem digitar URLs longas.

segno LAN Discovery PNG / Base64

Screen Wake Lock API

Dispositivos móveis tendem a suspender threads de WebSockets quando a tela escurece. O botão "Manter tela ligada" aciona a API W3C WakeLock para manter a GPU e as antenas operando com taxa de atualização máxima durante sua partida.

Aviso de Certificado HTTPS no Celular: Por que é normal?

Ao abrir a página no Chrome ou Safari, o navegador alertará que o certificado é desconhecido. Isso acontece porque o certificado TLS é gerado localmente na hora para proteger o túnel WSS na sua rede privada. Clique em "Avançado → Continuar para o site (não seguro)" para prosseguir.

Troubleshooting

Matriz de Diagnóstico & Resolução

Encontrou algum comportamento inesperado? Consulte nossa base de soluções rápidas.

O app informa: "Driver não instalado" ou falha ao criar pad

O Windows precisa do driver de barramento de kernel ViGEmBus para simular controles Xbox 360.

✓ Solução Recomendada

Clique no botão INSTALAR DRIVER na interface do GhostPad. Confirme a permissão de administrador do Windows e reinicie o computador uma única vez para registrar o serviço XUSB.SYS.

O celular não consegue abrir a página ou dá "Tempo Esgotado"

Ocorre quando o celular e o computador estão em redes diferentes ou o Firewall bloqueou a porta.

✓ Solução Recomendada

1. Verifique se o smartphone está conectado exatamente no mesmo roteador Wi-Fi que o PC.
2. Certifique-se de que a rede no Windows está definida como "Rede Privada" e não "Rede Pública".
3. Se o roteador tiver isolamento de clientes (AP Isolation), desative-o nas configurações do Wi-Fi.

Controle aparece como "NÃO DETECTADO" no navegador do celular

Por motivos de privacidade e economia de bateria, a Gamepad API do navegador não divulga a existência de controles até que um botão seja fisicamente pressionado.

✓ Solução Recomendada

Pareie o controle no Bluetooth do celular e aperte qualquer botão (X, Quadrado, D-Pad). O status mudará imediatamente para verde com o nome do controle.

Porta 8443 já está em uso

Outra instância do GhostPad ou outro serviço web (ex: Docker, Apache) está ouvindo nessa porta.

✓ Solução Recomendada

Feche outras janelas do GhostPad no Gerenciador de Tarefas ou altere a constante PORTA = 8443 no arquivo ghostpad.py para outra porta livre (ex: 8888 ou 9443).

Dois controles virtuais aparecem no joy.cpl do Windows

Você pode ter deixado duas abas do navegador abertas no celular ou em outro aparelho da casa.

✓ Solução Recomendada

Feche abas antigas ou duplicadas no navegador do celular para manter apenas uma sessão ativa de WebSocket.
